Kinvox

The record is the product. So the design is a document.

Kinvox calls an ageing parent on schedule, and picks up when she calls in. It captures what she said, verbatim, and cites the rule that fired — never a diagnosis. This page is the visual system that has to carry that: warm paper, hairlines, and her own words set larger than anything around them.

Neutrals

A warm paper ramp

Every existing token is warmed and the relationships between them are kept, so nothing needs relayout. Pure #fff becomes a paper white and every grey picks up the same yellow bias — the change is small per swatch and total in aggregate.

Accent — one, and it is not blue

Deep forest green

Green rather than the reflexive clinical blue: it reads calm and trusted, it doubles honestly as the “confirmed” status, and it sits properly on warm paper where blue goes cold and sour.

accent#1B4D3EBrand, landing CTA, active nav, focus ring
accent-soft#E6EDE9Fill behind selected chips and the active nav row

The primary button stays ink-filled. The wireframe spec sets “one accent: black”, and the whole severity language is built on ink-on-white weight. Accent is spent on the landing CTA, active nav and focus rings only — so the logic the app already has survives intact.

Status

Added on top of shape, never replacing it

Three status colours and one highlight. Each is applied to a mark that already carries a distinct shape and a text label — so the screen still reads in a greyscale screen recording, and for a colour-blind viewer.

ok#1B4D3EConfirmed, taken, step complete, consent ticked
warn#8A5A00Watch severity, no answer, unknown
warn-soft#F6EEDCWatch chip fill
danger#A4231CP1, red severity, missed dose, critical alert
danger-soft#F7E7E4Critical card tint
highlight#F3E7C4The transcript line that fired the rule

Vermilion, not fire-engine red. danger belongs to the paper it sits on. warn is a dark ochre — dark enough to set as text at 6.5:1, so it can carry a word rather than only decorate one. And highlight is a pale marigold: the marked passage in a record. Today that matched line uses the same grey as the skeleton bars, so the most important line on the most important screen currently reads as a loading placeholder.

Typography

One family for both scripts she speaks

The app loads no webfont today. It needs three roles — and the Devanagari one is not a nicety: the verbatim Hindi quote is the product’s centrepiece, and a Latin-only UI face silently drops it to a system fallback while everything around it is set properly.

Motion

Slow and settling

No spring, no bounce, nothing over 500 ms. Every animation answers one question: what changed? There are currently zero transitions, zero keyframes and five hover rules in about 7,600 lines.
